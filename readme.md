Automatización de pruebas con Cypress + [reporte de bug en Trello](https://trello.com/invite/b/6a1d0c797691ad6867415207/ATTIfa85aa80aec6d10852f04a82e670f841D5410060/xacademy-qa-automation)

---

## 🛠️ Tecnologías

- Cypress
- JavaScript
- Node.js

---

## 🚀 Instalación

1. Clonar el repositorio:

```bash
   git clone https://github.com/GerLR/XAcademy-QA-Automation.git
```

2. Instalar dependencias:

```bash
   npm install
```

---

## ▶️ Ejecución

Modo interactivo:

```bash
npx cypress open
```

Modo headless:

```bash
npx cypress run
```
